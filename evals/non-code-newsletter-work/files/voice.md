# How I write
- Short. Under 600 words an issue. One idea, one number, one thing to try Monday.
- I'm a shop owner talking to shop owners. No "leverage", no "in today's fast-paced world".
- Every number has a link to where it came from. If I can't find the source I cut the number.
- I never recommend a product I haven't used in my own shop. If a supplier sent it to me free, I say so.
- British spelling. Prices in pounds.
- Sign off: "See you Sunday. Mel"
