# Streaks: a habit tracker I can actually stick to

A small web app, phone first. I want to build it over the next couple of weekends with Claude Code.

## Must have
- Add a habit with a name and an emoji. Edit and delete it.
- Tap a habit to mark it done today. Tap again to undo.
- Each habit shows its current streak and longest streak.
- A week view: seven dots per habit.
- Works offline; data stays on the phone (no accounts, no server).
- Installable to the home screen (PWA).

## Nice to have
- A reminder notification at a time I pick.
- Export my data as a file.
- Dark mode.

## Stack
I don't mind. Something simple that Claude is good at. I know a bit of JavaScript.
